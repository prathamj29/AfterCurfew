# AfterCurfew — Project Guidelines

## Stack
- Vanilla HTML, CSS, JS (no frameworks)
- Vite for dev/build (`npm run dev`, `npm run build`)
- Firebase Realtime Database (REST API)

## Design System
Follow `aftercurfew-premium` design skill for all UI work:
- Apple-inspired dark + blue (#007AFF) aesthetic
- Inter font, premium minimal style
- Bottom tab bar, bottom sheets, glassmorphism

## Git Workflow
- This project is shared via GitHub
- Split work across files to avoid merge conflicts
- Never push to main without asking

## Code Conventions
- No comments in code
- No emojis in code or UI elements unless specifically asked
- Use CSS custom properties, not inline styles
- ES modules for JS (import/export)
